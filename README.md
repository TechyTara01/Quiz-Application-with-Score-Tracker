# Quiz App with Score Tracker

## About the Project

The Quiz App with Score Tracker is a beginner-level Python project designed to provide users with a simple way to attempt multiple-choice questions from different subjects and check their performance.

The idea behind this project is to make quiz practice more organised and interactive. Users will be able to select a subject, answer questions with four options, and receive a score based on their answers.

At the current stage, we have developed the basic quiz code in Python. The project is still under development, and we plan to add more features as we continue working on it.

## Current Features

- Multiple-choice questions with four options.
- Quiz logic for checking answers.
- Score calculation based on correct answers.

## Planned Features

- Subject selection.
- User details before starting the quiz.
- Saving previous quiz attempts.
- Score history and performance tracking.
- A more user-friendly interface.

## Technology Used

- Programming language: Python
- Frontend: Python GUI
- Backend: Pyhton

## Project Status

The project is currently in its initial development stage. The basic quiz code has been written, while additional features are planned for future development.
